## Архитектура
GitHub (исходники) → GitHub Pages (HTTPS) → iframe в блоке Tilda T123 → страница Tilda.
Vercel и сторонний хостинг не нужны. Проект «Межгород Онлайн», «Ярмарка 4 сезона» и основной сайт MOZGIKOM LAB не затрагиваются.

Ключевые файлы интеграции:
- `tilda-t123-loader.html` — загрузчик для блока Tilda «HTML-код» (T123): создаёт iframe на GitHub Pages, слушает сообщения моста, автоматически подстраивает высоту и возвращает страницу к началу iframe при переходах.
- `js/bridge.js` — дочерний мост (подключён ко всем страницам): сообщает родителю высоту контента (`bpla-height`), готовность (`bpla-ready`) и навигацию (`bpla-navigation`).
- `.github/workflows/pages.yml` — публикация на GitHub Pages (только файлы сайта, без служебных `.md`).

## Содержание и решения
- Страницы: Главная, О проекте, Материалы, FAQ, Контакты, кастомная 404.
- Hero: «Беспилотная авиация», подзаголовок «Технологии. Люди. Возможности.», кнопки «О проекте»/«Материалы»/«Контакты».
- Материалы: карточки «Видео»/«Фото»/«Публикации» со статусом «материал ожидается»; реальные файлы вставляются только после подтверждения прав.

- P0 (выполнено локально): навигация между всеми страницами, отсутствие горизонтальной прокрутки на 360/375/393/430/768/1440 px, мобильное меню, `prefers-reduced-motion`, keyboard focus.

- P2: подстановка утверждённого логотипа и видеоролика после передачи файлов.

## Безопасность и публикация
Перед правкой T123 делать резервную копию; менять только разрешённый блок T123. Не публиковать секреты, токены и персональные данные. Не обходить защитные проверки. После публикации проверять действующую страницу, а не только GitHub Pages.
