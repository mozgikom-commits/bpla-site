## Архитектура
GitHub (исходники) → GitHub Pages (HTTPS) → iframe в блоке Tilda T123 → страница Tilda.
Vercel и сторонний хостинг не нужны. Проект «Межгород Онлайн», «Ярмарка 4 сезона» и основной сайт MOZGIKOM LAB не затрагиваются.

Ключевые файлы интеграции:
- `tilda-t123-loader.html` — загрузчик для блока Tilda «HTML-код» (T123): создаёт iframe на GitHub Pages, слушает сообщения моста, автоматически подстраивает высоту и возвращает страницу к началу iframe при переходах.
- `js/bridge.js` — дочерний мост (подключён ко всем страницам): сообщает родителю высоту контента (`bpla-height`), готовность (`bpla-ready`) и навигацию (`bpla-navigation`).
- `.github/workflows/pages.yml` — публикация на GitHub Pages (только файлы сайта, без служебных `.md`).
