# «Беспилотная авиация» — демонстрационный сайт-предпросмотр

Локальный, полностью автономный адаптивный сайт-предпросмотр о направлениях
беспилотной авиации. Создан по брифу заказчика для согласования визуальной
концепции **до** проверки полномочий и получения утверждённых материалов.

> ⚠️ Это **демонстрационная версия**, а не официальный государственный ресурс.
> Контент нейтральный: без призывов, без условий службы/выплат/льгот, без
> выдуманных характеристик, персональных данных и закрытой информации.

## Стек

Компактный статический стек без внешних зависимостей и без сборки:

- **HTML5** (семантика, `lang="ru"`, SEO-meta, `alt`, aria, focus states)
- **CSS** (кастомные токены, cinematic editorial / drone technology, mobile-first)
- **JS** (мобильное меню, reveal-анимации, `prefers-reduced-motion`)
- **Node.js** (`>=18`) — только для локального HTTP-сервера и проверок

Весь визуал — собственный SVG/CSS (координатная сетка, диагональная оранжевая
линия, геометрическая схема беспилотника). Никаких чужих фото/логотипов.

## Запуск (одна команда)

```bash
cd bpla-standalone-preview
npm start            # или: node server.mjs
```

Откройте в браузере: **http://127.0.0.1:4173/** (порт подбирается автоматически,
если 4173 занят; можно задать явно: `PORT=8080 npm start`).

Чистые маршруты: `/`, `/about`, `/materials`, `/faq`, `/contacts`.
Неизвестные адреса возвращают кастомную 404 с кодом `404`.

## Проверка

```bash
cd bpla-standalone-preview
npm run check   # статическая проверка: файлы, HTML-структура, ссылки, JS-синтаксис
npm test        # интеграционный тест: сервер + HTTP-коды всех маршрутов
npm run build   # аналог npm run check (сборки нет — статический стек)
```

## Публикация в Tilda (блок T123)

Сайт размещается на GitHub Pages и встраивается на страницу Tilda через блок
«HTML-код» (T123). Загрузчик находится в [`tilda-t123-loader.html`](./tilda-t123-loader.html):

1. Разместить исходники в репозитории `mozgikom-commits/bpla-site` и включить
   GitHub Pages (workflow уже настроен в `.github/workflows/pages.yml`).
2. Скопировать содержимое `tilda-t123-loader.html` целиком в блок T123 страницы
   `https://plan-leading-bullhead.tilda.ws/`.
3. Если репозиторий назван иначе — поменять `SITE_URL` в загрузчике.

Мост `js/bridge.js` (подключён ко всем страницам) сообщает блоку T123 высоту
контента и навигацию, поэтому iframe растягивается без двойной прокрутки.

## Дизайн

Собственный стиль по четырём референсам пользователя — **cinematic editorial /
drone technology**:

- фон `#101516` / `#1B2425`, текст `#F2F0E9`, акцент `#E58D32`, олива `#838D7B`;
- крупные заголовки, моноширинные ярлыки, тонкие координатные линии (декор);
- layered cards, выразительная mobile-first сетка, умеренные плавные анимации;
- адаптивность **360px – 1440px+**, мобильная навигация, `prefers-reduced-motion`,
  видимый фокус для клавиатуры, контрастный текст, `skip-link`, SEO-meta.

5. **Контактные данные** — публикуются только после подтверждения.
